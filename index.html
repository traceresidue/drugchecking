Drug Checking Visualization Framework

A collection of 33 standalone, offline-capable visualizations for presenting drug checking data — from spectral analysis and chromatography to supply trends, geographic spread, point clouds, and experimental sonic formats. Each file opens directly in any modern browser with no server or network required.
